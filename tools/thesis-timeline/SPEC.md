# Thesis Roadmap & Timeline — SPEC

## Purpose

A single-page Gantt roadmap of the thesis project, from the original Miro plan to the
extended schedule. Communicates who owns what (author vs. thesis partner), current
status, and the runway to submission and defense. Doubles as a self-updating status
page: countdown to milestones is computed live from a `TODAY` constant.

## Scope

- Read-only visualization — no inputs, no persistence.
- Data is authored inline in the `<script>` `DATA` block; the chart re-renders from it.
- History (Feb–early Jul 2026) is taken from the original Miro board. Everything from
  `TODAY` forward is a working estimate and is expected to move.

## Data model (inline `<script>`)

```
SPAN       = { start, end }   // chart date range (ISO yyyy-mm-dd, parsed as UTC)
TODAY      = 'yyyy-mm-dd'      // drives the today line + countdown stats
SECTIONS[] = { group, owner, tasks[] }
  task     = { name, start, end, owner, status, note? }
MILESTONES[] = { label, date }
```

- **owner:** `sirio` (author — orange/red), `partner` (thesis partner — teal/blue),
  `shared` (integration — purple). Marius is referred to only as "thesis partner".
- **status:** `done` (muted fill), `active` (glow ring), `planned` (dashed + hatch).

## Layout constants

- Label column width: `--lbl: 210px` on `.timeline`.
- `.timeline` `min-width: 940px` → horizontal scroll inside `.gantt-scroll` on narrow
  screens (contained scroll, not page-body scroll).
- Bar positions computed as a percentage of the SPAN via `pct(dateStr)`; bars clamp to
  `[0, 100]%` and enforce a minimum visible width.
- Month gridlines + labels generated by iterating months across the SPAN.
- Milestone flags stagger vertically (even/odd) to reduce label overlap.

## Outputs / features

- Gantt with owner-coloured, status-shaded bars grouped by workstream.
- Today line, milestone diamonds/lines, month gridlines.
- Hover tooltip: name, date range, owner, status, note.
- Countdown stats: days to submission (15 Sep 2026), defense (28 Sep 2026), and the
  start of the writing sprint.

## Key dates (current design point)

- Thesis submission: **2026-09-15** (extended from the original July hand-in).
- Defense: **2026-09-28**.
- Writing sprint: ~4 weeks, `2026-08-17 → 2026-09-14` — mostly transferring existing
  documentation into LaTeX, not new research.
- First full module integration: `~2026-08-31` (none completed yet at `TODAY`).

## Assumptions

- The forward schedule overlaps intentionally (pump, alignment, testing run in parallel).
- Pump path: finalise single-channel → 4-channel build (4 liquids, validation) →
  design-only scale study toward 6 channels.
- Alignment path: MVP → queueing-system design (largest unknown) → print/assemble parts.
- Partner modules (storage, UI, electronics, operate-area) are largely prototyped and
  feed integration rather than needing new design from the author.

## Maintenance

Update the `DATA` block (and `TODAY`) as work progresses; the chart, milestones, and
countdowns all derive from it. No build step.
