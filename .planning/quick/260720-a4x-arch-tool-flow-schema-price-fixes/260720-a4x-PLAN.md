# Quick Task 260720-a4x — Architecture tool: schema font, price fold, page flow

Single file: `tools/system-architecture-explorer/index.html`. Three targeted
fixes. Style tokens stay as-is (user: "the style is there already"); the change
is legibility, affordance, and page flow — not a redesign.

## Task 1 — Whole-Device Module Schema: font too small
In `buildSchema()` the module boxes render SVG `<text>` at 9.5–12.5 in an
880-unit viewBox that scales down to the ~62% left column, so it renders tiny.
- Module title `labelSize` 12.5 → 15
- Payload chip text 9.5 → 12; grow chip rect height 16 → 18 and row pitch
  20 → 22 so the larger text still fits inside the fixed 120-tall boxes
- Liquid-barrier label 10 → 12; legend text 10 → 12
- Verify no chip text overflows its box (worst case: electronics "System bus
  (I²C / RS-485 / CAN)" in the 340-wide box; storage/pump in 180-wide boxes)

## Task 2 — Component unit prices: make expandability obvious
The `<details id="pricesFold">` is a bare summary with no container, so it does
not read as an expandable panel. Box it (border + glass bg + radius + padding,
same token family as the surrounding `.sae-card`s), add a hover border cue, and
keep the existing rotate-on-open ▸ marker. No content change.

## Task 3 — Overall page flow (user-selected scope)
The divider pills are inconsistent — "Part 00 / Design directions / Part 01 /
Part 02 / Diagram" — which breaks the sense of a walkthrough. Fix the flow:
- Renumber to a clean, consistent 4-step spine: Part 1 (schema) · Part 2
  (directions) · Part 3 (reasoning) · Part 4 (matrix)
- Make the per-variant diagram read as Part 4's companion (a non-numbered
  "Selected-variant view" label, tightened against the matrix) instead of a
  dangling terminal "Diagram" section — page now ends on the comparison step
- Even out vertical rhythm between the major steps (a touch more separation
  before each part-label) so the steps read as distinct beats
- Update the matching HTML comment banners for consistency
