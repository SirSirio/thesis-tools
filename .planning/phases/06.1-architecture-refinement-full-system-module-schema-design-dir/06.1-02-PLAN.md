<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `MODULES` label/payload/purpose strings → `#schemaNote` DOM | Static, author-written, in-repo strings. The only data→DOM path this plan adds. |
| SVG `<g data-module>` attributes → `selectModule(key)` lookup | Keys originate from the same in-repo `MODULES` object; a tampered DOM attribute can only select a non-existent key. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06.1-04 | Tampering | `MODULES` strings rendered into `#schemaNote` | mitigate | Task 3 mandates `textContent`/`createElement` or the existing `escapeHtml()` (index.html:793); raw `innerHTML` interpolation of module strings is prohibited and is an explicit acceptance criterion. Applies the same rule `sourceCellContent()` already enforces for the component table (T-06-06). |
| T-06.1-05 | Tampering | `selectModule(key)` reading a `data-module` value from the DOM | mitigate | Look the key up in `MODULES` and no-op on a miss, rather than trusting the attribute. Keys are never used to index anything outside the `MODULES` object. |
| T-06.1-06 | Denial of Service | `buildSchema()` rebuilding on every hover | accept | Rendered once at init; hover only toggles classes and swaps note text. Even if rebuilt, the SVG is a fixed ~six-box string with no unbounded loop. Client-side only, single user, offline. |
| T-06.1-SC | Tampering | Supply chain (npm/pip/cargo installs) | not applicable | No package manager in this project (CLAUDE.md: no build tools, no npm). This plan adds zero dependencies — the liquid-glass treatment is inline SVG `<filter>` primitives, not a library. |

**Not applicable, and why:** Spoofing / Repudiation / Information Disclosure / Elevation of
Privilege — no auth, no sessions, no accounts, no server, no roles, no PII, no network calls. SQLi,
CSRF, SSRF, authn/authz — no backend, no database, no state-changing requests. This is a static file
openable from a USB drive.
</threat_model>
