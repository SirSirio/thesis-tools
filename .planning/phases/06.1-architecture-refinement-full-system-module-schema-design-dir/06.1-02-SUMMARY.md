## Decisions Made
- Split the SVG `<g data-module>` grouping (Task 2, structural) from the interactive attributes/listeners (Task 3, behavioral) into separate commits, even though both touch the same `moduleBox()` function — kept each task's diff scoped to its own concern
- Picked "hover restores to the last sticky selection on mouseleave" over "click always wins outright" for the hover/selection conflict the plan flagged as needing a documented choice — see code comment above `selectModule()`
- Kept the sticky-note sketch's connectivity (liquid: Storage→Pump→Nozzle→Alignment; data: Software & Electronics↔everything else) but redesigned the spatial layout freely (D-05 explicitly allows this) for legibility: four modules in a top row, Alignment beneath, Software & Electronics + its liquid barrier at the bottom
- Reused `BOX()` for the liquid barrier itself (with a `titleTop`/`dash`/`filter`/`fill` extension) rather than hand-writing a separate rect, keeping all rounded-rect+label drawing through one closure
