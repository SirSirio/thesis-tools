### Task 3 — JS: IntersectionObserver animation + view swap

**File:** `prototypes/index.html` (edit — `<script>` block)

**Read first:** `prototypes/index.html` (Task 2 result)

Full script:

```javascript
// View swap — show detail for a given proto ID, hide journey
function showDetail(protoId) {
  document.getElementById('journey-view').hidden = true;
  document.getElementById('detail-view').hidden = false;
  document.querySelectorAll('.detail-section').forEach(s => { s.hidden = true; });
  const el = document.getElementById('detail-' + protoId);
  if (el) el.hidden = false;
  window.scrollTo({ top: 0, behavior: 'smooth' });
}

function showJourney() {
  document.getElementById('detail-view').hidden = true;
  document.getElementById('journey-view').hidden = false;
  window.scrollTo({ top: 0, behavior: 'smooth' });
}

document.getElementById('back-btn').addEventListener('click', showJourney);

document.querySelectorAll('.proto-card').forEach(btn => {
  btn.addEventListener('click', () => showDetail(btn.dataset.proto));
});

// Path draw + node pop-in via IntersectionObserver
const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
const stage = document.querySelector('.stage-inner');

if (!reducedMotion && stage) {
  const obs = new IntersectionObserver(entries => {
    if (entries[0].isIntersecting) {
      document.querySelector('.journey-path')?.classList.add('is-visible');
      document.querySelectorAll('.proto-node').forEach(n => n.classList.add('is-visible'));
      obs.disconnect();
    }
  }, { threshold: 0.1 });
  obs.observe(stage);
}
// reducedMotion=true: CSS default (stroke-dasharray:1 0, opacity:1) already shows everything
```

**Acceptance criteria:**
- Clicking proto-01 card: `#journey-view` gets `hidden`, `#detail-view` becomes visible, `#detail-proto-01` becomes visible, page scrolls to top
- Clicking ← Back to journey: `#detail-view` gets `hidden`, `#journey-view` becomes visible
- No console errors on load or interaction

  <p>The 5.0 µL/stroke target was set from the displaced-volume model assuming full tube occlusion with nominal geometry. The −32 % shortfall reveals the real occlusion efficiency is lower than modelled — likely the roller force under-squeezes the tube, the tube ID is slightly larger than assumed, or the axial contact length is shorter than the model predicts.</p>
  <p style="margin-top:12px">The primary insight: the geometry-model calibration constant matters more than expected. The gravimetric figure (3.39 µL/stroke, CV 4.5 %) is the new baseline for proto-02 redesign. The goal for proto-02 is to close the 5.0 → 3.4 gap — adjusting occlusion (tighter squeeze or larger rotor radius) using the displaced-volume tool with the measured correction target.</p>
</section>
