<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → page | The `lang` key is read from browser-local storage and used to select a dictionary branch |
| inline LANG dict → DOM | `applyLang()` assigns dictionary values via `innerHTML` |

This is a static page with no server, no auth, no session, no user-supplied input, and no network
calls at runtime. Web-application threats such as SQL injection, CSRF, and session fixation have no
surface here and are deliberately not listed.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | `applyLang()` `innerHTML` assignment | accept | Values come exclusively from the inline `LANG` object literal in the same document — an author-controlled, trusted constant, not user or network input. `innerHTML` (not `textContent`) is REQUIRED because keys such as `site-title` intentionally contain `<br>`. An attacker able to edit the inline dict already controls the whole document, so escaping would add no security boundary |
| T-07-05 | Tampering | `localStorage['lang']` read | mitigate | Already correct in the existing code and must stay so: the read is try/catch wrapped (line 509) and the result is validated against `if (!LANG[currentLang]) currentLang = 'en'` (line 510) before use, so a poisoned key falls back to English rather than indexing into undefined. Do not remove either guard while editing (LANG-03/LANG-04) |
| T-07-06 | Denial of service | Hero CSS animation | accept | A continuously looping compositor-only animation on 4 circles and one stroked path is negligible; it is transform/paint-only with no JS per frame, and `prefers-reduced-motion` provides the user opt-out |
| T-07-SC | Tampering | npm/pip/cargo installs | n/a — no installs | This plan installs zero packages and adds zero `<script src>` references. The font it consumes was vetted in plan 07-01. An acceptance criterion actively greps for `gsap`/CDN hosts to catch an accidental dependency being introduced |
</threat_model>
