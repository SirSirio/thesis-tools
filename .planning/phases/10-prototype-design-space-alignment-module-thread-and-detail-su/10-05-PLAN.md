# Plan 10-05 — Two-thread journey page

**Wave:** 2 (needs the three subpages to exist so its links resolve)
**Modifies:** `prototypes/index.html`

## Goal

Rebuild `prototypes/index.html` as a **journey page only**, carrying two independent
threads — pump (orange) and alignment (violet) — with every card linking out to the subpages
built in wave 1. The file goes from ~2210 lines to a few hundred.

## Tasks

### 1. Strip
Delete `<section id="detail-view">` entirely — both `.detail-section` blocks. Delete the
detail-view CSS from the inline `<style>` (it now lives in `assets/prototype-page.css`).
Delete the `showDetail()` / `hidden`-toggle view-swap logic, the KaTeX `<script>` tags, the
TOC builder and the lightbox. Keep only journey CSS and journey JS.

Also fix the stale back-link: the nav currently reads `← Resources`; every other page reads
`← All tools`.

### 2. De-singularize the thread structure
Wrap each thread in `<section class="thread thread--pump">` / `<section class="thread
thread--align">`, each containing its own heading block, its own `.journey-path-svg` with its
own `<path class="journey-path">`, and its own `.nodes-layer`.

Three JS lookups currently assume exactly one of everything and **all three must change**:
- `document.querySelector('.stage-inner')` → `querySelectorAll`, one IntersectionObserver
  per stage.
- the observer callback, which adds `.is-visible` to *all* `.proto-node`s on the page →
  scope it to the intersecting stage only, or scrolling to thread A animates thread B.
- `alignNodesToPath()`, which reads one `journeySvg` / `journeyPath` and loops every node →
  loop per thread, pairing each path with its own nodes.

### 3. Replace ID-keyed node positioning
`#node-proto-01 { top: 1% } … #node-proto-05 { top: 81% }` does not scale to a second thread.
Move to a per-node custom property (`style="--node-top: 21%"`) or an `nth-child` rule so each
thread spaces its own nodes.

`min-height: 2500px` is hard-coded on `.stage-inner` and `.nodes-layer` for exactly five
nodes. Make it per-thread — the four-node alignment thread needs a shorter stage or its curve
stretches over dead space.

### 4. Per-thread colour
Set the `--t-*` variables on the thread wrapper (values in `10-CONTEXT.md` §D-10-2) and
repoint `.proto-card:hover`, `.proto-card-tag`, `.proto-card-cta`, `.kpi-pill` borders, the
thread heading gradient and the path stroke at them.

**The path stroke is currently a hard-coded attribute on the SVG element**
(`stroke="rgba(255,107,43,0.25)"`). Remove it and set the stroke in CSS from `--t-path`, or
the alignment curve will be orange.

Do **not** override the global `--accent` — the nav, the blobs and every other page depend
on it. Note `--glass-border` is itself orange-tinted, so a card border must take `--t-border`
explicitly.

### 5. Cards become links
`<button class="proto-card" data-proto="…">` → `<a class="proto-card" href="…">`. Keep the
visual treatment; make sure focus states still work and the hit area is the whole card.

| Card | href |
|------|------|
| proto-01 | `Prototype-1-Pump-Module/proto-01-5ul-4roller/index.html` |
| proto-02 | `Prototype-1-Pump-Module/proto-02-5ul-4roller-v2/index.html` |
| Alignment V2 | `Prototype-2-Alignment-Module/index.html` |
| Alignment V2.1 | `Prototype-2-Alignment-Module/index.html#homing` |

Ghost cards stay non-interactive `<div>`s.

### 6. Alignment thread content
Four nodes per `10-CONTEXT.md` §D-10-6: **V2 · Rack indexing stage** (built), **V2.1 ·
Homing** (built + bench-validated), **V3 · Long-stroke redesign + axis 2** (ghost), **V4 ·
Rack queueing** (ghost). KPI pills on the built cards drawn from `PROTOTYPE.md`: `≤0.03 mm
repeatable zero`, `102 half-steps/mm`, `22 s full home`, and a warning pill for the stroke
shortfall. Thread heading: name the module and say in one line what it does — it moves the
samples, not the dispensing head.

## Verification

- Both threads animate **independently**: scroll so only one is in view and confirm the other
  has not revealed itself.
- Nodes sit on their own curve at 1440px, 1024px and 768px; on mobile (≤640px) both threads
  collapse to the stacked layout with the curves hidden.
- No horizontal scroll at 320px.
- Every card link resolves — click each one.
- Pump thread is pixel-unchanged in colour; alignment thread has no orange in it.
- With JS disabled, both threads render fully visible and all links work.
- `grep -c 'detail-section' prototypes/index.html` returns 0.
