<objective>
Resolve the RESEARCH.md-flagged contradiction on the owned screen's product page — the bitbyg listing is titled "SPI Touch Screen" but its body describes an "A0–A3 / D4–D13 / I2C on D0–D3" pin pattern characteristic of the 8-bit-parallel Uno-shield class. The two readings differ by roughly 6–8 Layer-A pins (SPI) vs 13–21 (parallel + touch + SD), which can flip several 6-parallel variants between "fits on a bare ESP32" and "does not fit." This must be settled by physically inspecting the board Sirio already owns, so 06-05's pin-budget defaults to a verified scenario rather than an unverified assumption.

Purpose: De-risk the biggest new-data ask (D-09) before it ships as an authoritative number. This is an early, blocking human-verify because the physical board is the only reliable source (the vendor page contradicts itself).
Output: A recorded verdict (SPI or 8-bit parallel), the resulting Layer-A fixed pin count, and a confidence tag, captured in this plan's SUMMARY for 06-05.
</objective>
