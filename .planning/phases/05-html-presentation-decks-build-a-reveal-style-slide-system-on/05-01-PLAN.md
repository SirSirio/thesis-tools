    Create assets/deck.js as a single IIFE / DOMContentLoaded-scoped module. Define a state object holding `slideIdx` (0-based), `fragmentIdx` (-1 = none revealed). Query `slides = Array.from(document.querySelectorAll('.slide'))` and cache `stage = document.querySelector('.deck-stage')`.
    fitStage (D-03, RESEARCH mechanic 1): `scale = Math.min(window.innerWidth/1280, window.innerHeight/720)`, `tx=(innerWidth-1280*scale)/2`, `ty=(innerHeight-720*scale)/2`, set `stage.style.transform = translate(tx,ty) scale(scale)`. Bind to `resize` and call once on load.
    Stepping (D-13, RESEARCH mechanic 2): `advance()` reveals the next unrevealed `.fragment` on the current slide (set `data-fragment-revealed`, bump fragmentIdx); when none remain, call `goToSlide(slideIdx+1)`. `retreat()` un-reveals the last revealed fragment; when none, `goToSlide(slideIdx-1, 'last')`. `goToSlide(idx, landAt)` guards bounds, moves `.slide--active`/`.slide--leaving` (remove `--leaving` after ~450ms via setTimeout matching the CSS duration — pitfall: do not snap), recomputes `fragmentIdx` (`'last'` = last fragment index, else -1), re-applies `data-fragment-revealed` up to fragmentIdx for back-nav, then calls `updateURL()` and `updateHUD()`.
    Hash routing (D-11, RESEARCH mechanic 3): `updateURL()` uses `history.replaceState(null,'', '#/'+(slideIdx+1))` — replaceState NOT pushState (file:// Firefox pitfall 3). `readURL()` parses `/^#\/(\d+)$/`, clamps, and goToSlide. Bind `readURL` to `hashchange` and run once on load.
    HUD (D-12): `updateHUD()` sets the progress-fill width to `((slideIdx+1)/slides.length)*100 + '%'`, the counter text to `(slideIdx+1) + ' / ' + slides.length`, and wires prev/next arrow buttons to `retreat()`/`advance()`. Optional idle-fade timer toggling a `.hud-idle` class is acceptable.
    Overview grid (D-14): build (or read authored) thumbnails into `.deck-overview`; `toggleOverview()` flips `document.body` `data-overview` and the panel's `.hidden` via `element.hidden` (mirror prototypes/index.html element.hidden pattern); clicking a thumb calls goToSlide and closes the overview.
    iframe focus capture (D-09, RESEARCH mechanic 4): for each `.iframe-overlay`, on click set overlay `display:none`, remove iframe `tabindex`, `iframe.focus()`, and `document.body.setAttribute('data-demo-active','')`. `deactivateIframe()` restores overlay, sets `tabindex="-1"`, blurs iframe, removes `data-demo-active`, and calls `stage.focus()`. Click-outside: a document click handler that, when `data-demo-active` is set and the target is not inside `.iframe-wrapper`, deactivates. Do NOT auto-deactivate on iframe `blur` (presenter may tab between fields).
    keydown handler — single listener with priority gating (pitfall 4 & 5): if `body[data-demo-active]` → only handle Escape (deactivateIframe + `e.stopPropagation()`), then `return` (deck keys disabled in demo mode). Else if Escape and `body[data-overview]` → closeOverview, return. Else dispatch deck keys: ArrowRight/Space → advance; ArrowLeft/Backspace → retreat; `o`/`O` → toggleOverview.
    reducedMotion guard (D-17): `const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;` — gate any JS-driven entrance motion on it (CSS transitions are already guarded in deck.css). Give the stage focus on load (`stage.focus()`) so keydown reaches the document. Native APIs only; no libraries, no CDN (D-15).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deck page → embedded `<iframe>` | The deck frames the project's OWN tool pages (rotor solver, displaced-volume model). Same-origin (same file tree on USB, same domain on GitHub Pages). No third-party / untrusted content is framed. |
| user → deck | Keyboard/click navigation only. No form input, no persisted data, no network calls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | iframe focus capture (deck.js) | mitigate | Overlay + `tabindex="-1"` keep the iframe inert until explicit activation; keydown is gated on `data-demo-active` so the embedded page cannot silently swallow deck navigation. Same-origin own content only — no `sandbox` needed and `focus()` is permitted. |
| T-05-02 | Information Disclosure | static site | accept | No PII, no secrets, no backend, no user input processed — nothing to disclose. Static HTML/CSS/JS served from USB or GitHub Pages. |
| T-05-03 | Tampering (supply chain) | external resources | mitigate | D-15 forbids any CDN/external resource (offline + GitHub Pages constraint). deck.css/deck.js are local, hand-authored, no package installs. No `@import url(http`, no `<script src=//>`. |
</threat_model>
