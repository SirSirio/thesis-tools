A new standalone tool page at `tools/gsd-workflow-guide/index.html` that:
- Follows the exact nav bar + bg-blobs + animate-in pattern from the rotor solver

### Task 3 — Node HTML content structure

Each `.flow-node` div has this internal structure:

```html
<div class="flow-node [optional]" data-cmd="discuss-phase">
  <div class="node-header">
    <span class="node-cmd">/gsd:discuss-phase N</span>
    <span class="node-badge optional-badge">optional</span>  <!-- only on optional nodes -->
    <span class="node-toggle" aria-hidden="true">▸</span>
  </div>
  <p class="node-brief">Lock in implementation decisions before planning</p>
  <div class="node-detail">
    <p>Asks open-ended questions about how to build the phase. Surfaces design details — layouts, API structures, error handling — to eliminate ambiguity before planning begins. Produces <code>CONTEXT.md</code>.</p>
  </div>
</div>
```

Core nodes (discuss, plan, execute): no `optional` class, no badge.  
Optional nodes (spec-phase, verify-work, code-review, ship): add class `optional` + include badge.

Each `.util-node` follows the same structure but uses class `util-node` instead of `flow-node`:

```html
<div class="util-node" data-cmd="progress">
  <div class="node-header">
    <span class="node-cmd">/gsd:progress</span>
    <span class="node-toggle" aria-hidden="true">▸</span>
  </div>
  <p class="node-brief">See current status and what step comes next</p>
  <div class="node-detail">
    <p>Auto-detects the next recommended command. Use <code>--next</code> to run it immediately. Central hub for situational awareness between phases.</p>
  </div>
</div>
```

Node content (brief + detail) for all 12 nodes — use `02-RESEARCH.md` Command Reference table verbatim.

### Task 5 — Expand/collapse JavaScript (`<script>` block)

Add inline `<script>` at the bottom of `<body>`:

```js
document.querySelectorAll('.flow-node, .util-node').forEach(node => {
  node.addEventListener('click', () => {
    node.classList.toggle('open');
  });
});
```

Multiple nodes can be open simultaneously (no forced collapse of others).
