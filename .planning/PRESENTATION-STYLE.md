# Presentation Style Guide

This document defines the recurring aesthetic standards for all presentation decks in this project, based on industry best practices (Garr Reynolds, Nancy Duarte, Guy Kawasaki) and project-specific aesthetic goals.

## 1. Design Philosophy
- **Embrace "Presentation Zen"**: Use empty space and high contrast. Do not fill every inch of the slide.
- **The Glance Test**: The audience should understand the slide's core message within 3 seconds.

## 2. Text Density
- **Minimum 30-Point Font**: Force constraints on text density by using large fonts.
- **Drastically Limit Bullet Points**: Strip out dense lists. Use shorter sentences.
- **Ban the Script**: Slides are visual support, not a teleprompter or a data-dump document.

## 3. Imagery & Data
- **Hero Visuals**: Images should be the focal point of the slide, often full-bleed or large-scale, rather than small decorative elements.
- **Avoid Data Dumps**: Focus on high-level concepts rather than raw numbers.
- **Purposeful Color**: Use color to highlight the *one* key insight (e.g., accenting a CV percentage while muting other data).

## 4. Action-Oriented Titles
- **Write Headlines, Not Labels**: Titles must state the conclusion or core insight so the audience immediately understands the "so what".
  - *Poor*: "Proto 1 Validation"
  - *Excellent*: "Proto-1 proved the concept but underdelivered"
- **Cohesive Narrative**: If you read only the titles of the deck sequentially, they should tell the complete story.
