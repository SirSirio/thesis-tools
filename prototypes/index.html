Proto 01 · Built 2026

5 µL 4-roller peristaltic — baseline

Purpose

First physical build. Objective: establish whether the roller-displaced-volume model geometry predictions translate into real dispense performance, and to measure how far the assumed 5.0 µL/stroke calibration constant deviates from reality. Served as the minimum viable prototype to detect systematic error before a targeted redesign (proto-02).

Design reasoning

The 5.0 µL/stroke target was set from the displaced-volume model assuming full tube occlusion with nominal geometry. The −32 % shortfall reveals the real occlusion efficiency is lower than modelled — likely the roller force under-squeezes the tube, the tube ID is slightly larger than assumed, or the axial contact length is shorter than the model predicts.

The primary insight: the geometry-model calibration constant matters more than expected. The gravimetric figure (3.39 µL/stroke, CV 4.5 %) is the new baseline for proto-02 redesign. The goal for proto-02 is to close the 5.0 → 3.4 gap — adjusting occlusion (tighter squeeze or larger rotor radius) using the displaced-volume tool with the measured correction target.
